Hypixel SkyBlockのテクスチャパックを無効にする方法

更新日 2026-10-20 · Minecraft Java 1.21.11, 26.1, 26.2, 26.3

無料のFabric MOD NoForcedPacksを入れてHypixelに参加し、設定 → リソースパックを開いてHypixel SkyBlockのパックを左へ移動します。参加するたびにオフのままです。Minecraft Java 1.21.11と26.1〜26.3で動作します。

ModrinthでNoForcedPacksをダウンロード CurseForge

Hypixel SkyBlockは、すべてのプレイヤーに独自のリソースパックを送ります。バニラのMinecraftでは受け入れるか遊ばないかしか選べず、パックはリソースパックの一覧にも表示されないため、オフにする方法がありません。NoForcedPacksはこれを変えます。SkyBlockのパックが一覧の普通の項目になり、オフにすることも、残して一部だけ削ることもできます。

手順

  1. お使いのMinecraftのバージョン（1.21.11、26.1.x、26.2、26.3）用のFabric Loaderをインストールします。Fabric APIは不要です。
  2. ModrinthからNoForcedPacksをダウンロードし、.jarをmodsフォルダに入れます。
  3. FabricのプロファイルでMinecraftを起動し、mc.hypixel.netに参加します。パックが読み込まれるようにSkyBlockへ移動します。
  4. 設定 → リソースパックを開きます。SkyBlockのパックは選択中にワールド固有のリソースとして表示され、その下にHypixel SkyBlock (server)があります。
  5. それを利用可能側へ移動し、完了をクリックします。アイテム、防具、メニューがバニラの見た目に戻ります。

選択は保存されます。次に参加したときもパックはオフのままです。元に戻すには、もう一度右へ移動してください。

パックは残して、一部のテクスチャだけを外す

新しいSkyBlockのテクスチャはだいたい好きだけど、いくつかは嫌い？パックはオンのままにして、個別テクスチャ（ポーズメニューのTXT パックボタン）を開きます。たとえばAspect of the Voidを検索してバニラに設定すれば、そのアイテムだけが元に戻ります。

上部のUIをオフにする…で、パックのUI（メニュー、HUD、ツールチップ）だけをオフにし、アイテムのテクスチャを残すこともできます。

よくある質問

MODなしでHypixel SkyBlockのテクスチャパックを無効にできますか？
実質できません。パックを拒否すると、それを必須にしているサーバーでは遊べません。また、バニラのMinecraftには一度受け入れたパックをオフにする設定がありません。NoForcedPacksのようなクライアント側のMODを使えば、オフにしたまま遊び続けられます。
SkyBlockのテクスチャパックを無効にするとBANされますか？
NoForcedPacksは自分の画面の見た目を変えるだけで、ゲーム上の有利にはなりません。それでもHypixelのルールは確認してください。使い方の責任は自分にあります。
パックをオフにしたら、ツールチップがマゼンタの四角になったのはなぜ？
SkyBlockの一部のアイテムは、Hypixelのパックにしかないツールチップのスタイルを参照しています。NoForcedPacksはこれを検出し、代わりにバニラのツールチップを表示します。
