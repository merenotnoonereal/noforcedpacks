如何停用 Hypixel SkyBlock 材質包

更新於 2026-10-20 · Minecraft Java 1.21.11, 26.1, 26.2, 26.3

安裝免費的 Fabric 模組 NoForcedPacks，進入 Hypixel，開啟選項 → 資源包，把 Hypixel SkyBlock 資源包移到左側。之後每次進入都會保持關閉。支援 Minecraft Java 1.21.11 以及 26.1 至 26.3。

在 Modrinth 下載 NoForcedPacks CurseForge

Hypixel SkyBlock 會傳送專屬的資源包給每位玩家。原版 Minecraft 只能接受或不玩，而且這個資源包不會出現在資源包清單中，所以沒辦法關閉它。NoForcedPacks 改變了這一點：SkyBlock 資源包會變成清單中的一般項目，你可以關閉它，也可以保留並精簡。

步驟

  1. 為你的 Minecraft 版本（1.21.11、26.1.x、26.2 或 26.3）安裝 Fabric Loader。不需要 Fabric API。
  2. 從 Modrinth 下載 NoForcedPacks，把 .jar 檔案放進 mods 資料夾。
  3. 使用 Fabric 設定檔啟動 Minecraft，進入 mc.hypixel.net。前往 SkyBlock，讓資源包載入。
  4. 開啟選項 → 資源包。SkyBlock 資源包會顯示在已選中，名稱為世界專屬資源，下方是 Hypixel SkyBlock (server)。
  5. 把它移到可用一側，然後點選完成。你的物品、盔甲和選單都會恢復為原版樣式。

你的選擇會被儲存。下次進入時，資源包仍會保持關閉。想恢復的話，再把它移回右側即可。

保留資源包，只拿掉部分材質

大部分新的 SkyBlock 材質你都喜歡，但有幾個很討厭？保持資源包開啟，開啟個別材質（暫停選單中的 TXT 資源包按鈕）。搜尋一個物品，例如 Aspect of the Void，然後設為原版。只有這個物品會恢復原樣。

你也可以用上方的關閉介面…只關閉資源包的介面（選單、HUD、提示框），同時保留它的物品材質。

常見問題

不用模組可以停用 Hypixel SkyBlock 材質包嗎？
基本上不行。如果你拒絕資源包，要求該資源包的伺服器不會讓你繼續玩，而原版 Minecraft 也沒有在接受後關閉資源包的設定。使用 NoForcedPacks 這類用戶端模組，才能關閉它並繼續遊戲。
停用 SkyBlock 材質包會被封鎖嗎？
NoForcedPacks 只改變你自己螢幕上看到的內容，不提供任何遊戲優勢。不過，請查看 Hypixel 的規則：如何使用由你自己負責。
關閉資源包後，為什麼我的提示框變成了洋紅色方塊？
部分 SkyBlock 物品使用的提示框樣式只存在於 Hypixel 的資源包中。NoForcedPacks 會偵測到這種情況，並改為顯示原版提示框。
