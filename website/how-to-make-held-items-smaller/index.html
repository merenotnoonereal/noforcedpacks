How to make held items smaller in Minecraft

Updated 2026-10-20 · Minecraft Java 1.21.11, 26.1, 26.2, 26.3

Vanilla Minecraft has no setting for held item size. Install the free Fabric mod NoForcedPacks, open Individual Textures → Held items, and lower Item size (10% to 200%). The same screen changes your swing speed (5% to 200%).

Steps

  1. Install Fabric Loader (Minecraft Java 1.21.11, 26.1.x, 26.2 or 26.3) and put NoForcedPacks in your mods folder. No Fabric API needed.
  2. Join a world or server, press Esc and click TXT Packs.
  3. Click Held items at the bottom of the screen.
  4. Drag Item size down to shrink the item in your hand, or up to make it bigger. Your hand stays visible behind the screen, so you see the result live.
  5. Drag Swing speed to slow your swing animation down or speed it up, and press Test swing to try it without hitting anything.

Reset puts both back to 100%. Settings are saved across restarts.

Does it change attack speed?

No. Only your own first-person animation changes. Attacks, mining and everything the server receives are exactly the same, and other players see you as usual. That makes it safe to use on servers like Hypixel, though you should always check a server's rules.

Also in the same mod

NoForcedPacks also turns off forced server resource packs (like Hypixel SkyBlock's) and lets you combine textures from several packs item by item.

FAQ

Is there a vanilla setting to make held items smaller?
No. Minecraft Java has no option for the size of the item in your hand. A client-side mod like NoForcedPacks adds one.
Does changing swing speed change my attack speed?
No. It only changes your own swing animation on your screen. Attacks, mining and what the server receives stay the same.
Can other players see my smaller held items?
No. Item size and swing speed only change your own first-person view.
