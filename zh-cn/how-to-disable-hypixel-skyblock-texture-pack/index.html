如何禁用 Hypixel SkyBlock 材质包

更新于 2026-10-20 · Minecraft Java 1.21.11, 26.1, 26.2, 26.3

安装免费的 Fabric 模组 NoForcedPacks，进入 Hypixel，打开选项 → 资源包，把 Hypixel SkyBlock 资源包移到左侧。之后每次进入都会保持关闭。支持 Minecraft Java 1.21.11 以及 26.1 至 26.3。

在 Modrinth 下载 NoForcedPacks CurseForge

Hypixel SkyBlock 会给每位玩家发送自己的资源包。原版 Minecraft 只能接受它或者不玩，而且这个资源包不会出现在资源包列表中，所以没有办法关闭它。NoForcedPacks 改变了这一点：SkyBlock 资源包会变成列表中的普通一项，你可以关闭它，也可以保留并精简。

步骤

  1. 为你的 Minecraft 版本（1.21.11、26.1.x、26.2 或 26.3）安装 Fabric Loader。无需 Fabric API。
  2. 从 Modrinth 下载 NoForcedPacks，把 .jar 文件放进 mods 文件夹。
  3. 使用 Fabric 配置启动 Minecraft，进入 mc.hypixel.net。前往 SkyBlock，让资源包加载。
  4. 打开选项 → 资源包。SkyBlock 资源包显示在已选中，名称为世界特定资源，下方是 Hypixel SkyBlock (server)。
  5. 把它移到可用一侧，然后点击完成。你的物品、盔甲和菜单都会恢复为原版样式。

你的选择会被保存。下次进入时，资源包仍然保持关闭。想恢复的话，再把它移回右侧即可。

保留资源包，只去掉部分材质

大部分新的 SkyBlock 材质你都喜欢，但有几个很讨厌？保持资源包开启，打开单独材质（暂停菜单中的 TXT 资源包按钮）。搜索一个物品，例如 Aspect of the Void，然后设为原版。只有这个物品会恢复原样。

你也可以用顶部的关闭界面…只关闭资源包的界面（菜单、HUD、提示框），同时保留它的物品材质。

常见问题

不用模组能禁用 Hypixel SkyBlock 材质包吗？
基本不能。如果你拒绝资源包，要求该资源包的服务器不会让你继续玩，而原版 Minecraft 也没有在接受后关闭资源包的设置。使用 NoForcedPacks 这样的客户端模组，才能关闭它并继续游戏。
禁用 SkyBlock 材质包会被封号吗？
NoForcedPacks 只改变你自己屏幕上看到的内容，不提供任何游戏优势。不过，请查看 Hypixel 的规则：如何使用由你自己负责。
关闭资源包后，为什么我的提示框变成了品红色方块？
部分 SkyBlock 物品使用的提示框样式只存在于 Hypixel 的资源包中。NoForcedPacks 会检测到这种情况，并改为显示原版提示框。
