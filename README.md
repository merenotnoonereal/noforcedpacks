# NoForcedPacks: Disable, Bypass or Skip Server Resource Packs

> Turn off any server's forced resource pack, including the **Hypixel SkyBlock texture pack**. Mix textures from multiple packs item by item, and make held items smaller or change your swing speed. Client-side Fabric mod for Minecraft Java, **no Fabric API needed**.

NoForcedPacks is a **100% client-side Fabric mod** with three tools:

- **Disable any forced server resource pack**, like the Hypixel SkyBlock texture pack.
- **Mix textures from multiple packs**, item by item, or turn off single textures and a pack's UI.
- **Change your held items**: make them smaller or bigger and change your swing speed.

Nothing to install on the server, so it works on Hypixel and any other server. Your choices are saved across reconnects and restarts.

## Features

### Disable, bypass or skip server resource packs
- The server's pack shows up in your normal **Options → Resource Packs** list. Move it off and it stays off.
- Your own packs are never touched.

### Mix and combine textures from multiple packs
- **Pick which pack's texture you see**, per item. Every loaded pack that textures that item is an option.
- **Pick between variants** a pack ships for one item. Starred versions keep their own look.
- **Turn a single texture off** (set it to **Vanilla**) and keep the rest of the pack.
- **Turn off just a pack's UI** (HUD, inventory and menu backgrounds, tooltips, title screen, SkyBlock menu icons) and keep its item and armor textures.
- **Search by name**, for example `Aspect of the Void`.
- Worn armor follows your choice, and tooltips from a turned-off pack fall back to vanilla instead of magenta boxes.

![Choosing a texture for one item from multiple packs](https://cdn.modrinth.com/data/uIJyKdPm/images/ecc8a431fb7fc0d565c939b6bc8f407a7fb0b812.gif)

### Smaller held items and custom swing speed
- **Item size** from 10% to 200%.
- **Swing speed** from 5% to 200%, with a **Test swing** button.
- Only you see it. Attacks, mining and what the server receives stay the same.

## Installation
1. Install [Fabric Loader](https://fabricmc.net/use/). You don't need Fabric API.
2. Download NoForcedPacks from [Modrinth](https://modrinth.com/mod/noforcedpacks) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/noforcedpacks).
3. Drop the `.jar` into your `mods` folder and launch.

## Usage
- **Whole pack off:** join the server, open **Options → Resource Packs** and move the server pack to the left.
- **Textures, UI and held items:** open **Individual Textures** from the **TXT Packs** button in the pause menu, the **Individual textures** button on the Resource Packs screen, or a key you choose in **Options → Controls → Key Binds** (unbound by default).

## FAQ
- **How do I disable the Hypixel SkyBlock texture pack?** Install NoForcedPacks, join Hypixel, open Options → Resource Packs and move the SkyBlock pack off. It stays off next time.
- **How do I bypass a server's forced resource pack?** Vanilla only lets you accept it or leave. NoForcedPacks accepts the pack and then lets you turn it off on your side, on any server.
- **Can I disable only specific textures?** Yes. Set any item to Vanilla in Individual Textures, or turn off only a pack's UI.
- **Can I combine texture packs?** Yes. Pick, per item, which loaded pack's texture you see.
- **Do I need Fabric API?** No. Only Fabric Loader.
- **Needed on the server?** No. It's fully client-side.
- **Is it bannable?** It only changes what you see and gives no gameplay advantage, but check your server's rules.
